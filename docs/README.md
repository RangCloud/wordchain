# 문서

말꼬리 프로젝트의 기획·품질·출시 관련 문서를 모아 둔 폴더다.

| 문서                                                                           | 내용                                                                                                                    |
| ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| [기획서](https://claude.ai/code/artifact/5b12347f-b96b-41f1-aa20-4d171be902ff) | 로드맵, 기술 스택, 기능 명세(기능 ID G-01~), API 명세, 테스트 계획(TC-W-01~18)                                          |
| `qa/`                                                                          | 출시 전 QA 결과 보고서(엑셀): 테스트 케이스와 수행 결과, 결함 목록, 자동 테스트·성능 측정, 스토어 출시 체크리스트, 증적 |
| `privacy-policy.md`                                                            | 개인정보처리방침. 앱은 개인정보를 수집하지 않으며, 최고 기록과 진동 설정만 기기에 저장한다                              |
| `store/`                                                                       | 스토어 등록용 이미지: Play 아이콘(512×512), 그래픽 이미지(1024×500)                                                     |

테스트 케이스와 결함은 기획서의 기능 ID(G-xx)와 테스트 ID(TC-W-xx)로 서로 연결된다.
