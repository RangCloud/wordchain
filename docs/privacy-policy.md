# 말꼬리 개인정보처리방침

시행일: 2026년 ○월 ○일

말꼬리(이하 "앱")는 이용자의 개인정보를 수집하지 않습니다.

## 1. 수집하는 개인정보
앱은 이름, 이메일, 전화번호, 기기 식별자, 위치, 연락처 등 **어떠한 개인정보도 수집하지 않습니다.**
회원가입·로그인 기능이 없으며, 광고·분석(애널리틱스) 도구를 사용하지 않습니다.

## 2. 기기에만 저장되는 정보
다음 정보는 이용자의 기기 안에만 저장되며, 외부(개발자 서버 포함)로 전송되지 않습니다.

| 항목 | 목적 | 삭제 방법 |
|---|---|---|
| 난이도별 최고 점수 | 홈 화면에 최고 기록 표시 | 앱 삭제 또는 앱 데이터 삭제 |
| 진동 설정(켬/끔) | 설정 유지 | 앱 삭제 또는 앱 데이터 삭제 |

## 3. 네트워크 통신
앱은 게임 진행에 인터넷 연결을 사용하지 않습니다. 단어 사전과 AI는 모두 기기 안에서 동작합니다.

## 4. 제3자 제공 및 위탁
수집하는 개인정보가 없으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다.

## 5. 아동의 개인정보
앱은 연령과 관계없이 개인정보를 수집하지 않습니다.

## 6. 사전 데이터 출처
앱의 단어는 국립국어원 표준국어대사전의 자료를 가공하여 사용했으며, 크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국 라이선스(CC BY-SA 2.0 KR)를 따릅니다. 앱은 국립국어원과 관련이 없습니다.
