# 말꼬리 (Wordchain)

AI와 한 판 2~3분 동안 끝말잇기를 하는 캐주얼 게임 (두음법칙 정확 판정).

> 📄 기획서(로드맵 · 기술 스택 · 기능 명세 · 테스트 계획): https://claude.ai/code/artifact/5b12347f-b96b-41f1-aa20-4d171be902ff

## 구조

```text
wordchain/
├─ apps/
│  ├─ mobile/   # Expo SDK 54 + TypeScript + expo-router
│  └─ api/      # FastAPI + uv
├─ docs/        # 기획 · 명세 · 테스트 케이스 · 회고
├─ .github/workflows/ci.yml
├─ .vscode/     # 추천 확장 · 저장 시 포맷 · F5 디버깅 · 작업(Tasks)
└─ CLAUDE.md / AGENTS.md
```

## 처음 실행하기 (Windows PowerShell)

```powershell
# 1) VS Code로 열기 → 오른쪽 아래 '추천 확장 설치' 클릭
code C:\dev\wordchain

# 2) 앱
cd apps\mobile
npm install
npx expo start          # a: Android 에뮬레이터 · w: 웹 브라우저 · QR: 휴대폰 Expo Go

# 3) 서버 (새 터미널)
cd apps\api
uv sync
copy .env.example .env
uv run uvicorn app.main:app --reload --port 8000   # 또는 VS Code에서 F5
uv run pytest -q
```

## 현재 화면 (기본 UI)

| 경로 | 화면 | 상태 |
| --- | --- | --- |
| `index` | 홈: 난이도 선택, 최고 기록, 게임 시작 | 임시 기록 |
| `game/[id]` | 게임: 목숨, 점수, 타이머, 단어 체인, 시작 글자 힌트, 입력 | 임시 진행 상태 |
| `result/[id]` | 결과: 승패, 점수, 사용 단어와 뜻 | 임시 결과 |
| `rules` | 규칙과 두음법칙 예시 | 완료 |
| `settings` | 효과음 · 진동 · 정보 | 화면 상태만 |

### 지켜야 할 조건 (출시 전 점검표)

저작권 정책은 상업적 용도를 포함한 자유 이용을 허용하므로 **광고를 붙인 앱 출시가 가능하다.** 대신 아래를 지킨다.

- [ ] **저작자 표시**: 앱의 설정 > 정보 화면, 플레이 스토어·앱 스토어 설명, 이 README에 아래 표기 문구를 넣는다.
- [ ] **변경 사실 표시**: 원본을 가공했다는 사실을 표기 문구에 함께 적는다.
- [ ] **동일조건변경허락**: 가공한 사전 데이터(SQLite 파일 등)를 배포하거나 공개할 때는 같은 라이선스(CC BY-SA 2.0 KR)를 적용한다. 앱·서버 소스 코드는 사전과 별개의 저작물로 보고 이 조건의 대상에 넣지 않는다.
- [ ] **가공 데이터 공개**: 가공한 사전 데이터를 누구나 같은 조건으로 받을 수 있게 공개한다(GitHub 릴리스 등). 앱 스토어의 복제 방지 기술이 사전 자료의 재이용을 막는다는 해석을 피하기 위한 조치다.
- [ ] **제외 자료 미사용**: 정책상 별도 허락이 필요한 자료는 쓰지 않는다. 출전이 있는 용례(예문), 이미지·소리·발음 등 다중 매체 파일이 해당한다. 사전 구축 스크립트는 표제어·품사·뜻풀이만 읽는다.
- [ ] **보증·제휴 오인 금지**: 국립국어원의 로고를 쓰지 않고, 국립국어원이 이 앱을 만들었거나 인증·후원한다는 인상을 주는 문구를 쓰지 않는다.
- [ ] **원본 미커밋**: 내려받은 원본(`apps/api/data/raw/`)은 저장소에 올리지 않는다.
