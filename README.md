# 말꼬리 (Wordchain)

AI와 한 판 2~3분 동안 끝말잇기를 하는 캐주얼 모바일 게임이다. 표준국어대사전에서 가져온 약 21만 개 명사로 단어를 판정하고, 두음법칙(력 → 역, 녀 → 여 등)을 정확히 인정한다.

## 게임 소개

- 난이도는 쉬움 · 보통 · 어려움 세 가지다. 한 턴 제한 시간은 15초(어려움 10초)이고 목숨은 3개다.
- 앞 단어의 마지막 글자(두음법칙 적용 글자 포함)로 시작하는 2글자 이상 명사를 입력한다. 이미 나온 단어는 다시 쓸 수 없고, 첫 턴에는 이어갈 단어가 없는 한방단어를 쓸 수 없다.
- AI가 이을 단어를 찾지 못하면 플레이어가 이긴다. 시간 초과·목숨 소진·기권이면 진다.
- 점수는 받아들여진 단어마다 글자 수 × 10점, 승리 시 100점이며 난이도 배율(1.0 · 1.5 · 2.0)을 곱한다. 난이도별 최고 기록은 기기에 저장된다.

### AI 상대

AI는 LLM이 아니라 사전 탐색 알고리즘이다. 없는 단어를 지어내지 않고, 응답이 빠르며(실제 사전 기준 수 ms), 시드를 고정하면 같은 수를 둬서 자동 테스트로 재현할 수 있다.

| 난이도 | 전략                                                                      |
| ------ | ------------------------------------------------------------------------- |
| 쉬움   | 3글자 이하 단어 중 상대가 잇기 쉬운 끝 글자를 고른다                      |
| 보통   | 사전 전체에서 무작위로 고른다                                             |
| 어려움 | 상대가 잇기 가장 어려운 끝 글자로 몰고, 자기 5번째 수마다 한방단어를 쓴다 |

## 화면

| 경로          | 화면                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| `index`       | 홈: 난이도 선택, 난이도별 최고 기록, 게임 시작                            |
| `game/[id]`   | 게임: 목숨, 점수, 타이머, 단어 체인, 다음 시작 글자(원고지 칸), 단어 입력 |
| `result/[id]` | 결과: 승패와 종료 사유, 점수, 이번 판에 나온 단어                         |
| `rules`       | 규칙과 두음법칙 예시                                                      |
| `settings`    | 진동 설정, 사전 출처·버전 정보                                            |

디자인 콘셉트는 "원고지"다. 단어와 시작 글자를 원고지 칸에 담고, 라이트·다크 모드를 모두 지원한다.

## 아키텍처

- **앱 단독(오프라인) 실행**: 단어 판정, AI, 타이머, 점수를 모두 앱 안의 엔진(`engine.ts` · `localGame.ts`)이 처리한다. 게임 중 네트워크 요청이 없고 개인정보를 수집하지 않는다.
- **단어 목록 내장**: 표준국어대사전에서 2글자 이상 명사 표제어만 뽑은 목록(약 21만 개, 약 2.4MB)을 앱에 넣고, 첫 게임을 시작할 때 읽어 들인다.
- **서버(`apps/api`)**: 같은 규칙 엔진과 AI를 Python으로 구현한 게임 API다(세션 · 요청 제한 포함). 사전 구축 스크립트도 여기에 있다.
- **같은 규칙, 같은 테스트**: 앱(TypeScript)과 서버(Python)의 규칙은 같게 유지한다. 한글 분해·두음법칙은 `shared/hangul-vectors.json`의 같은 테스트 벡터로 양쪽을 함께 검증한다.
- **순수 함수 규칙 엔진**: 판정과 AI는 UI·DB·시계를 모르는 순수 함수다. 시각과 난수를 밖에서 받으므로 '마감 1.5초 후 제출' 같은 경계값을 테스트에서 그대로 재현할 수 있다.

## 실행하기 (Windows PowerShell)

```powershell
# 앱
cd apps\mobile
npm install
npx expo start          # a: Android 에뮬레이터 · w: 웹 브라우저 · QR: 휴대폰 Expo Go
npm test                # 단위 테스트 (node:test)
npm run typecheck
npm run lint

# 서버 (새 터미널)
cd apps\api
uv sync
copy .env.example .env
uv run uvicorn app.main:app --reload --port 8000
uv run pytest -q
```

앱 빌드(EAS)는 `apps\mobile`에서 실행한다. 예: `eas build -p android --profile preview`
